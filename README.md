# Ridgehold

A long-session settlement game on a high ridge. Lay roads, raise houses, farms, a mill, palisades, woodcamps, and a quarry. Villagers walk to their work. Seasons turn. The valley does not always stay quiet.

No accounts. The ledger stays in this browser.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Keep the fold

- Drag to orbit, right-drag to pan, scroll to zoom.
- Keys `1`–`7` choose a building. `R` turns it. Click the ridge to raise it.
- `X` pulls a building down and returns half the timber and stone.
- Space holds the day. `I` `II` `III` in the bar are steady, brisk, and a hard wind.
- Roads to the hall make fields, mills, and camps earn their keep.
- Farms feed the fold. A staffed mill on the same road lifts nearby fields.
- Houses add beds. Full stores and spare beds bring new households up the ridge.
- Winter thins the harvest. Palisades slow raiders climbing out of the cut.
- **Keep ledger** writes the ridge into local storage. It also saves itself as the day goes on.
